# C1.5 — The odin gateway Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Canvas permission edges become real IAM: workloads get per-node AWS creds, one gateway endpoint verifies SigV4 → classifies (service, action, resource) → evaluates edge-compiled policies → forwards allowed requests to the real backings (re-signed for RustFS), returns protocol-correct AccessDenied otherwise.

**Architecture:** PRD `docs/superpowers/specs/2026-07-22-gateway-prd.md` (requirements + validated internals). Reference implementations for every hard part live in `.superpowers/sdd/research-iam-gateway.md` (SigV4 verify/re-sign, classifier tables, evaluator, proxy loop, latency methodology) — implementers MUST read the relevant report section before their task; the code there is prototype-grade truth, to be productionized not reinvented.

**Tech Stack:** starlette/FastAPI (raw ASGI request handling), botocore internals (SigV4), httpx (forwarding), uvicorn second listener in-process (pattern: a uvicorn.Server on a thread, like the old embed).

## Global Constraints

- Requirements R1–R8 and the v1 cut in the PRD bind every task; deferred list items must FAIL CLEANLY (explicit 400/501 + event), never mis-evaluate.
- Default-deny. Explicit-deny-wins. The compiler only emits Allow + canonical casing; never `?`, `NotAction`, `NotResource`, `Condition`.
- The gateway is stateless: keys + policies live in a registry object rebuilt from (Stack, issued keys) — no DB, no caches that outlive an Apply.
- SigV4 verify recomputes with the request's ORIGINAL `X-Amz-Date`; never `add_auth` on the incoming request. Reject `STREAMING-*` content-sha256 explicitly.
- Gateway port: `ODIN_GATEWAY_PORT` env var, default 4266, bound on 0.0.0.0 (containers reach it via host.docker.internal).
- Keys persist to `.odin/{env}/keys.json` (server restart must not orphan running containers' creds).
- `uv` never pip; imports at top; Pathlib; minimal branching; unit suite green per task; integration marked. Commit per task; controller pushes.

### Task G1: keys + policy (the pure core)

**Files:** Create `src/odin/gateway/__init__.py`, `src/odin/gateway/keys.py`, `src/odin/gateway/policy.py`; Test `tests/gateway/test_keys.py`, `tests/gateway/test_policy.py` (+ `tests/gateway/__init__.py`)

**Interfaces (later tasks consume verbatim):**
- `keys.KeyStore(root: Path)`: `issue(env: str, node_id: str) -> tuple[str, str]` (stable per (env,node) — reissue returns the SAME pair until `revoke`; access key format `AKODIN` + 14 urlsafe chars; secret 40 urlsafe chars), `lookup(access_key: str) -> Principal | None` (`Principal` = frozen dataclass `env: str, node_id: str`), `revoke_env(env: str) -> None`. Persists `.odin/{env}/keys.json` on every mutation; loads lazily.
- `policy.compile_policies(stack: Stack) -> dict[str, list[Statement]]` — node_id → statements from `kind == "iam"` edges (src=workload, dst=resource node); each edge → one Allow `Statement(actions=tuple[verbs], resources=tuple[resource names])` where the resource name is the dst node id (label). Verbs pass through verbatim (canvas already offers canonical AWS casing); compiler NEVER emits deny/NotAction/etc.
- `policy.evaluate(statements: list[Statement], action: str, resource: str) -> bool` — the research evaluator productionized: `*` and prefix wildcards in actions (`s3:Get*`, `s3:*`, `*`), resource `*` and exact match, case-sensitive (we control both sides), default-deny. (Explicit-deny support exists in the evaluator for future use + is tested, but the compiler never emits it in v1.)

**Steps:** [ ] read research report §4 (evaluator + its 14 cases — port ALL of them as tests) → [ ] failing tests (keys: issue-stable/lookup/revoke/persist-reload via tmp_path; policy: the 14 evaluator cases + compile from a hand-built Stack with 2 iam edges + a non-iam edge ignored) → [ ] implement → [ ] `uv run pytest tests/gateway/ -q` green, suite green, ruff clean → [ ] commit `feat(gateway): keys + edge-compiled policies + evaluator (G1)`.

### Task G2: sigv4 + classify

**Files:** Create `src/odin/gateway/sigv4.py`, `src/odin/gateway/classify.py`; Test `tests/gateway/test_sigv4.py`, `tests/gateway/test_classify.py`

**Interfaces:**
- `sigv4.verify(method, url, headers, body, secret_for: Callable[[str], str | None]) -> str | None` — returns the access key on valid signature else None; parses the `Authorization` SigV4 header (algorithm/credential scope/signed headers/signature), recomputes via botocore with the ORIGINAL X-Amz-Date; handles UNSIGNED-PAYLOAD; returns None for STREAMING-* (caller 501s). Service + region are read from the credential scope — expose `sigv4.scope(headers) -> tuple[service, region] | None`.
- `sigv4.resign(method, url, headers, body, access_key, secret, service, region) -> dict` — fresh SigV4 headers for the forwarded request (research: build an AWSRequest and SigV4Auth(...).add_auth on the OUTBOUND copy only).
- `classify.classify(service: str, method: str, path: str, query: dict, headers: dict, body: bytes) -> tuple[str, str] | None` — (action like "s3:GetObject", resource name) or None (unmappable → caller denies). dynamodb/sqs via X-Amz-Target; sns via Action param (+ TopicArn parsing for resource); s3 via the 16-row table from research §3 incl. multipart; S3 resource = first path segment (path-style), object ops still scope to the bucket name in v1; unknown S3 subresource → None.

**Steps:** [ ] read research §2+§3; port the capture-sink harness into `tests/gateway/harness.py` (captures real boto3 requests against a local sink — this is how sigv4/classify tests generate REAL inputs, no hand-built fixtures) → [ ] failing tests: 20-case verify matrix (valid × 4 services, wrong secret, tampered body, unknown key, unsigned-payload, streaming rejected) + 22-case classify matrix from the research tables → [ ] implement → [ ] gates green → [ ] commit `feat(gateway): SigV4 verify/re-sign + request classifier (G2)`.

### Task G3: the proxy app + errors

**Files:** Create `src/odin/gateway/app.py`, `src/odin/gateway/errors.py`; Modify `src/odin/server.py` (lifespan: start/stop the gateway listener; `app.state.gateway`); Test `tests/gateway/test_proxy.py`

**Interfaces:**
- `app.GatewayState`: `update(env, statements_by_node, backing_ports: dict[str, int])` (called on apply/tick; service → host port of that env's backing), plus the KeyStore. All lookups env-scoped.
- `app.create_gateway_app(state, keystore, on_deny: Callable) -> Starlette` — one catch-all route: verify (401 InvalidClientTokenId on unknown key / SignatureDoesNotMatch on bad sig, service-shaped) → scope → classify (unmappable → AccessDenied + event) → evaluate (deny → protocol-correct AccessDenied via `errors.access_denied(service, action)`: XML for s3/sns, JSON `__type` for dynamodb/sqs-json) → forward via httpx to `127.0.0.1:{backing_port}` (re-sign for s3 with the backing creds from `odin.aws.backings`; pass-through creds otherwise), stream response back verbatim. `on_deny(principal, action, resource, reason)` fires for every deny.
- `server.py`: lifespan starts uvicorn.Server(gateway app) on `ODIN_GATEWAY_PORT` (default 4266) in a thread (the old embed.py pattern — see git history of src/odin/aws/embed.py `start_ministack` for the exact shape); stops it on shutdown. Deny events → `ws_manager.broadcast({type: "access_denied", env, resource_id: node, action, target: resource})` + events log.
- Unit tests drive the Starlette app with httpx.ASGITransport + the harness-captured requests against a fake backing (a tiny ASGI echo recording what arrived — asserts re-signed Authorization changed access key, body byte-identical, deny paths shaped right per service, boto3 client pointed at the app raises ClientError with Code=AccessDenied).

**Steps:** [ ] read research §1 (proxy loop + resign gotchas) → [ ] failing tests → [ ] implement → [ ] gates green → [ ] commit `feat(gateway): checking reverse proxy + protocol-shaped denials (G3)`.

### Task G4: the injection swap (reconciler + goaws host + UI copy check)

**Files:** Modify `src/odin/reconcile/reconciler.py` (`_run_service` env building), `src/odin/aws/backings.py` (goaws.yaml Host → gateway; expose `backing_ports()`), `src/odin/server.py` (reconcilers get keystore+gateway state; wire `GatewayState.update` into apply/tick); Test: extend `tests/reconcile/test_reconciler.py`, `tests/aws/test_backings.py`

**Behavior:**
- `_run_service` for workload kinds: replace `self._aws.aws_env()` injection with: `ak, sk = keystore.issue(env, rid)`; env vars = `{"AWS_ENDPOINT_URL": f"http://host.docker.internal:{gateway_port}", "AWS_ACCESS_KEY_ID": ak, "AWS_SECRET_ACCESS_KEY": sk, "AWS_DEFAULT_REGION": REGION}`. (Per-service endpoint vars die — ONE endpoint now. Backings become loopback-only from the workload's perspective; they are reached only through the gateway.)
- BUT backing containers themselves and PROVISIONED observation keep using direct backing clients (host-side) — unchanged.
- goaws.yaml `Host` becomes `host.docker.internal` + `Port` the GATEWAY port (returned QueueUrls re-dial through the gateway — research flag). The canonical QUEUE_URL fact likewise points at the gateway now.
- `/destroy` → `keystore.revoke_env(env)` after prune.
- `GatewayState.update(env, compile_policies(stack), aws.backing_ports())` called at the end of every `tick()` (cheap, idempotent) — policies always track the applied Stack.
- Unit tests: injected env has exactly the 4 vars with the issued pair; two nodes get DIFFERENT keys; destroy revokes; goaws.yaml Host/Port assertion updated; `backing_ports()` shape.

**Steps:** [ ] failing tests → [ ] implement → [ ] `uv run pytest -q` green (some Task-4-era assertions on per-service endpoint vars will need updating — that's expected spec churn, update them) → [ ] commit `feat(gateway)!: workloads get per-node creds + one gateway endpoint (G4)`.
